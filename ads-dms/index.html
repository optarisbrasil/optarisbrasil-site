Natural · Adabas · ConsistADS · DMS

Seus sistemas Natural e Adabas livres para escolher a plataforma, sem reescrever nada e sem reaprender nada

O ConsistADS executa as aplicações Natural sobre banco relacional, com o mesmo código-fonte. O DMS leva os dados do Adabas para DB2, Oracle, MySQL ou outro banco relacional. No Brasil, as duas tecnologias da Consist Software Solutions Inc são licenciadas com exclusividade pela Optaris do Brasil.

O que resolvemos

O sistema funciona. A questão é o que custa mantê-lo e de quem ele depende

Aplicações em Natural e Adabas estão entre as mais estáveis das empresas que as usam, e é justamente por isso que continuam em produção. O ConsistADS e o DMS tratam do que está em volta delas: custo, pessoas, continuidade e acesso aos dados.

Custo que cresce sem ninguém decidir

A licença de plataformas como Natural e Adabas costuma acompanhar a capacidade instalada; em mainframe, medida em MSU. Quando o ambiente cresce ou o hardware é renovado, a base de cálculo sobe junto.

Conhecimento que não se repõe

Natural e Adabas não têm formação regular no mercado. A equipe que sustenta esses sistemas carrega décadas de regra de negócio e é o maior ativo deles. A saída precisa preservar essa equipe, não substituí-la.

Continuidade sob o olhar do regulador

A Resolução CMN nº 4.893/2021 pede alternativas de continuidade em caso de extinção de contratos de serviço, e a Lei nº 14.133/2021 exige justificativa formal para cada contratação de fornecedor exclusivo.

Dados difíceis de abrir

Com os dados em Adabas, levá-los para BI, analytics, novos aplicativos ou IA exige esforço específico. Em banco relacional, eles ficam acessíveis a qualquer ferramenta que fale SQL.

ConsistADS

Runtime para aplicações Natural
  • ✓Executa os programas Natural convertidos automaticamente, com o código-fonte inalterado.
  • ✓Traduz os comandos de acesso a dados (FIND, READ, GET, STORE) para SQL por baixo, com plano de acesso gerado automaticamente, em modo dinâmico ou estático.
  • ✓A equipe não vê nem precisa escrever esse SQL: continua programando como sempre. Manter em SQL é possível, se o cliente quiser.
  • ✓Substitui a camada de segurança e integração e permite expor a aplicação como web service e conviver com Java.
  • ✓Interface web pelo navegador, sem emulador de terminal, como opção.

ConsistDMS

Data Migration System
  • ✓Extrai os dados do Adabas, reformata, cria as tabelas no destino e carrega.
  • ✓Trata as estruturas que não existem no modelo relacional puro, como campos multivalorados e grupos periódicos.
  • ✓Destino em DB2, Oracle, MySQL ou outro banco relacional, dentro ou fora do z/OS.
  • ✓Gera o mapeamento entre os arquivos Adabas e as tabelas relacionais usado pelo ConsistADS.
  • ✓Pode ser usado isoladamente, para levar os dados ao relacional sem migrar os sistemas.

Possibilidades

Seis caminhos com as mesmas duas tecnologias

Cada empresa tem uma estratégia de plataforma diferente. ConsistADS e DMS se combinam para atender a cada uma delas, do projeto completo de migração ao uso só dos dados.

Maior impacto

Migração completa: programas e dados

O ConsistADS assume a execução dos programas Natural e o DMS leva os dados para o relacional. É a rota de maior impacto: elimina a dependência da plataforma original sem reconstruir o ativo.

z/OS

Ficar no mainframe, com DB2

Para quem quer permanecer em z/OS: o Adabas dá lugar ao DB2 e a aplicação segue no mainframe, com as mesmas telas e a mesma operação.

LUW

Sair do mainframe para Linux, Unix ou Windows

Leva o sistema para plataforma aberta, com os recursos de compatibilidade z/OS → Linux desenvolvidos em produção na Telefónica. Outras origens são avaliadas no assessment.

Menor investimento

Aproveitar o banco que você já tem

Se a empresa já licencia DB2 ou outro banco relacional, o ConsistADS substitui a camada Natural e usa o banco existente, sem nova compra de banco de dados.

Sob consulta

Abrir os dados para BI e IA

Uma cópia dos dados do Adabas em banco relacional, via DMS, para consulta, analytics e IA, sem migrar nem revalidar os sistemas legados.

Deyel

Evoluir com a Deyel por cima do legado

Com os dados em banco relacional, a Deyel constrói novos aplicativos, portais e processos sobre o que já funciona, e os agentes de IA operam dentro das regras do AI Runtime, com auditoria.

Perguntas frequentes

ConsistADS e DMS, em respostas curtas

Para licenças e preços dos produtos Consist, veja a página de licenças Consist.

Preciso reescrever os programas Natural?

Não. Os programas são convertidos automaticamente para o formato do ConsistADS e o código-fonte permanece o mesmo, com a mesma lógica de negócio.

Os programadores vão precisar aprender SQL?

Não. A tradução dos comandos de acesso a dados para SQL acontece por baixo, de forma transparente. A equipe continua mantendo os programas com FIND, READ e STORE, como sempre fez. Programar em SQL passa a ser possível, mas é uma escolha do cliente, não uma exigência.

Preciso sair do mainframe?

Não. Há duas rotas: permanecer no mainframe, em z/OS com DB2 no lugar do Adabas, ou levar o sistema para Linux, Unix ou Windows. A rota é definida no assessment, de acordo com a estratégia da empresa.

Os usuários vão precisar de treinamento?

Não necessariamente. As telas podem continuar exatamente como estão hoje. A interface web, sem emulador de terminal, é uma opção para quando fizer sentido, não uma imposição.

Posso migrar só os dados, sem mexer nos sistemas?

Sim. O DMS migra os dados do Adabas para banco relacional de forma independente. Uma linha voltada apenas a consultar e analisar os dados, sem migrar e revalidar os sistemas, pode ser avaliada caso a caso no assessment.

Quanto tempo leva um projeto?

Depende do tamanho do ambiente: volume de programas, arquivos Adabas e integrações. O prazo sai do assessment. O projeto pode ser executado pela equipe do próprio cliente, com o nosso apoio técnico.

Já migrei os sistemas, mas preciso consultar o legado. Há saída?

Sim. Para aplicativos Consist, a licença Read Only dá acesso somente de consulta ao ambiente, com 5 usuários fixos. Condições na página de licenças Consist.
